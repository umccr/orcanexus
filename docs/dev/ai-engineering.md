# AI engineering

- The AI documentation follows the Kiro structure (https://kiro.dev/docs/how-kiro-works/),
  since `kiro-cli` is the AI agent we use.
- Focus on grounding the agent's context with what matters most to the project specification
  and development scope.
- Agent guidance lives in `.kiro/steering/` and stays short. Human documentation lives in
  `docs/`; see [docs/README.md](../README.md) for where things go.

Less is more: avoid text bloat.
